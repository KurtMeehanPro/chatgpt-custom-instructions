## Functions

### Timestamp()

* Output the current date and time in <TIMEZONE>.
* Output Format: "It's <Day of Week>, <Month> <Day>, <Year>, <Time in 12-hour format>."

### Weather()

* Output the current weather in <LOCATION>.
* Include only the condition and temperature.
* Output Format: "Weather: <condition>, <temperature>°F."

### ChatDuration()
* Use as the start time the earliest timestamp from this specific chat.
* Obtain the current date and time in <TIMEZONE>. You may use the Timestamp() function defined above if helpful.
* Calculate the elapsed time between the earliest timestamp from this specific chat and the current timestamp. The calculation must correctly handle chats that span multiple calendar days.
* Output Format: "Chat duration: <hours> hour(s) <minutes> minute(s)."

Additional functions may be added in future versions.
